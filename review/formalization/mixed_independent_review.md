**Findings requiring an explicit scope decision**

1. **Finite piecewise constant hard inputs: missing formal strengthening, not a failure of the main theorem.** `MixedFrontier.State` stores an arbitrary globally integrable density for each row, a frontier, a strict cumulative ceiling, a positive constant tail, and pair coefficient inequalities on the prefix. It does not store a finite partition or a finite-step predicate. `initial` is a constant cell, and `advance` visibly builds a finite combination of prefix restrictions and constant cells; nevertheless, `exists_batch`, `capture_rounds`, and `exists_hard_cap` return an existential `State` with no reachability or finite-step certificate. In particular, the final success hypothesis quantifies over *all* states, including states with a nonconstant negative prefix. A protocol's success guarantee only on finite-step densities cannot currently be substituted directly for that hypothesis. The construction strongly supports the claimed strengthening mathematically, but the strengthening is not an exported Lean theorem. A repair would retain a reachability witness from `initial` through finitely many `advance` operations, or thread a finite-step invariant through the existential capture results, prove closure, and restrict both the hardness and success hypotheses to that family. Reflection must preserve the same certificate. This is blocking only for a claim that the finite-step strengthening itself is formally closed.

2. **Attempted versus answered cost: favorable mismatch, with a short formal adapter still needed at the reviewed snapshot.** `OracleProtocol.queryCost` is the supremum of the lengths of answered traces. A terminal illegal call is recorded separately and not included. On every legal successful return it equals the number of attempted calls; on an illegal execution it is one smaller than the paper's attempted-call count. Infinite legal querying has infinite cost, and query-free nonreturn after finitely many answers has the correct finite cost. Thus the proved answered-cost lower bound already implies the paper's attempted-cost lower bound by pointwise domination and monotonicity of the integral. There is no omitted failed-trial conditioning. For a literally matching formal endpoint, add an attempted cost, prove domination, and transport the supremum result. Do not describe the existing `queryCost` as the exact attempted count without this distinction.

3. **Raw malformed output and query encodings: missing normalization adapter, not a restriction on endpoint freedom.** `IntervalAllocation.Allocation` accepts an arbitrary natural number of interval records, arbitrary real endpoints, arbitrary owners, and proof fields for geometry, disjointness, and full coverage. It permits every finite fragmentation pattern after the usual null-endpoint normalization. However, it has no malformed-return constructor. `Query Agent` also has no invalid agent name or invalid query constructor; malformed bracket geometry and illegal signed targets *are* represented and handled. A general protocol using raw finite encodings can be normalized by rejecting invalid syntax, discarding invalid allocations, and canonically assigning the finitely many endpoints. This preserves successful physical values because the valuations are atomless, cannot add queries, and is measurable for the standard finite-coordinate encodings. That concrete normalization is not proved in the reviewed endpoints. A generic measurable decoder/postprocessor theorem would prove the transport for encodings satisfying its interface, but a fully closed correspondence claim still needs a concrete decoder instance or an explicit declaration that the canonical encoding is the formal model. The decoder's required property should be validity and value preservation, not a fairness or hardness premise.

**Adversary and replay review**

The hard-state conditions are geometric and analytic rather than success predicates. The initial state is explicitly inhabited, including at `Agent = Fin 3` and `α = 1`. The new-cell coefficient is `-((1 + α) / α) * tail j`, which is the paper's `-(1 + 1/α) * tail j`. The chosen row remains literally unchanged, and every other row is rebuilt from the old prefix, a negative constant cell, and a positive compensating tail. The normalization and strict ceiling proofs are derived from the actual interval integrals of these densities.

The physical obstruction uses two nonowners instead of averaging all nonowners. This is a valid strengthening of the certificate used in the manuscript: pair coefficient inequalities hold for every distinct pair, and integrating the transfer density yields a sum of two envy gaps at least `2 * α`. The shares used in that integration are actual measurable sets, not free utility variables or assumed fractional mass tables. Full interval output coverage supplies a tail owner, and disjointness supplies the nonowner relations. This handles arbitrary refinements within the prefix.

The protected trace includes every answered query and the possible terminal illegal request. Prefix coordinates are frozen; endpoint `1` is handled by the strict cumulative ceiling. Eval replies are correctly treated as values rather than spatial coordinates. For an old Cut reply in the prefix, the first-root property is preserved by agreement on every earlier point. For an old reply at `1`, the new strict ceiling prevents an earlier root at the same cumulative level. Invalid bracket geometry is input independent. For a geometrically valid illegal target, preserving bracket endpoint values preserves illegality.

The next query is obtained from the actual exhausted bounded execution. On tapes with a chosen row and bounded query coordinates, preserving that row preserves the new answer, while recursive replay preserves the previous history. Formal dummy descriptors after terminal behavior do not resume or decide a nonreturn. `run` checks its cap on an ask, so it still observes a return or query-free divergence after the last permitted answer. This avoids an off-by-one loss of valid finite outputs.

Capture uses finite row selection followed by a deterministic coordinate quantile. Each query stage retains at least a `1/(2n)` fraction and output capture retains one further half. The rate `1 / (2 * (2n)^fuel)` is positive for every finite horizon. Both zero-measure and zero-horizon cases are covered. The output quantile takes the maximum of the coordinates strictly below the exceptional endpoint; measurability is proved even when the finite list length varies without a bound. Previously captured tapes stay protected after extensions. A protected capped execution cannot become successful under a later state: its capped transcript and returned output are preserved, and the physical tail obstruction applies again. Exhaustion is correctly only a *capped* failure; no argument wrongly identifies it with eventual nontermination.

There is no infinite limit of profiles. A finite number of batches makes the complement of the protected set smaller than any prescribed positive `δ`. Each intermediate state and measurable tape set is fixed while its probability is measured. The final existential state depends on the law, protocol, parameters, horizon and tolerance, but not on the sampled tape.

**Measurability review**

The least-root rule is not assumed measurable. `RootBelow` is a projection of a closed relation with witness space `[0,1]`, which is compact. Rational lower-threshold decompositions then prove measurability of the selected first root on the physical legal domain. A separate legal-domain predicate is closed. The actual oracle returns `none` outside that domain, so no measurability assertion about an unconstrained choice of roots is needed. The mirrored query map is measurable and transforms the actual first-root reply into the last-root reply.

Lists, actions, queries, stops, and allocations use coordinate/disjoint-union encodings with the ordinary real measurable structure; there is no discrete measurable structure silently imposed on real coordinates. The execution map is proved measurable from the joint next-action rule and oracle measurability. `MeasurableViews` and `MeasurableRuns` are intermediate interfaces, but the final `expected_queries_unbounded` theorems discharge them using the standard next-action hypothesis. No measurability in a space of input profiles is assumed. Success is a countable union of measurable finite-return events, and actual cost is a countable supremum of trace lengths.

**Rightmost-specific review**

`RightmostOracle.oracle P` is initially indexed by the *unreflected* profile and answers on `reflectedProfile P`. This indexing could have hidden a mismatch, but `RightmostCorrespondence` closes it: `greatestOracle` is indexed by its own physical profile; it is legal on that profile and returns a `LastRoot`; reflection of actual densities has exactly the reflected cumulative profile; and the adversary oracle equals `greatestOracle` on those reflected rows. The reflected output obstruction uses actual reflected densities and removes only the null endpoint where the half-open convention differs.

The formal rightmost proof is a direct mirrored capture proof. It does not formalize the manuscript's extra-Eval simulation with a factor-two cost. This is an acceptable proof difference because the theorem proved is already about the original rightmost protocol's actual queries. Internal computation of a bracket value in the mathematical oracle definition does not expose an extra reply to the protocol.
